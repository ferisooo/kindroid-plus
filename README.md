# Kindroid+

Kindroid (kindroid.ai) in its own Android app. Log in once and stay logged in.

**Download:** https://github.com/ferisooo/kindroid-plus/releases/latest/download/KindroidPlus.apk

In a Kin's chat, your Kin's selfies take turns as the chat background. Tap the 🖼 button for
the order (random, newest, oldest), the speed (1 second to 5 minutes) and the message boxes
(solid, see-through, very see-through, invisible).

✨ Scene ideas: add your own AI key (Claude, ChatGPT, Gemini, Grok or DeepSeek), then tap
"✨ Ideas" on Kindroid's scene setting box to get a scene written for you.
