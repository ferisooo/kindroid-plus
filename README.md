# Kindroid+

Kindroid (kindroid.ai) in its own Android app. Log in once and stay logged in.

**Download:** https://github.com/ferisooo/kindroid-plus/releases/latest/download/KindroidPlus.apk

In a Kin's chat, tap the 🖼 button to make your Kin's selfies take turns as the chat background
(random, newest or oldest first, every 5 seconds to 5 minutes).
